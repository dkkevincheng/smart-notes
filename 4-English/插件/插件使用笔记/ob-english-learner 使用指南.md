# ob-english-learner 使用指南

> YouTube 语言学习插件使用教程

---

## 📋 插件信息

| 项目 | 内容 |
|------|-------|
| 名称 | OB English Learner |
| 版本 | 1.12.0 |
| 功能 | YouTube字幕获取、翻译、SRT生成 |
| 兼容 | Obsidian 0.15.0+ |

---

## 🔧 功能特性

### 1. 字幕获取
- 自动从YouTube获取字幕
- 支持多种语言

### 2. AI翻译
- 支持多API：OpenAI、DeepSeek、SiliconFlow、Gemini、阿里百炼
- 批量翻译处理
- 流式输出

### 3. SRT生成
- 自动生成字幕文件
- 支持标点修复
- 分割合并

---

## 📝 使用步骤

### Step 1: 安装插件
1. 下载 `ob-english-learner` 插件
2. 将插件文件夹放入 `.obsidian/plugins/`
3. 在 Obsidian 中启用插件

### Step 2: 配置API
1. 打开插件设置
2. 选择 AI 提供商
3. 填写 API Key

### Step 3: 使用流程
1. 播放 YouTube 视频
2. 获取字幕
3. 选择翻译语言
4. 生成 SRT 文件

## ❓ 常见问题

### Q: 翻译失败？
A: 检查 API Key 是否正确，网络是否正常

### Q: 字幕获取失败？
A: 视频必须有字幕才能获取
